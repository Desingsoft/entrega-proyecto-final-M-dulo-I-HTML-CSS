# Capital Solutions Informatics (CSI)

Landing page académica para una startup de soluciones tecnológicas.

## Tecnologías

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons

## Secciones

1. Hero / Inicio
2. Sobre nosotros
3. Nuestros servicios
4. Soluciones / ¿Por qué CSI?
5. Contáctanos
6. Footer

## Características

- Diseño responsive.
- Navbar adaptable a dispositivos móviles.
- Sistema de navegación por anclas.
- Animaciones CSS.
- Tarjetas de servicios.
- Formulario de contacto de demostración.
- Botón volver arriba.
- Personalización de Bootstrap mediante CSS.

## Ejecución

Abrir `index.html` en un navegador. Para una experiencia de desarrollo más cómoda se recomienda utilizar VS Code con Live Server.
