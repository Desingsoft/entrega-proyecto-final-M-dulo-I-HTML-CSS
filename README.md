# Capital Solutions Informatics (CSI)

Landing page académica para el emprendimiento **Capital Solutions Informatics**, desarrollada con HTML5, CSS3, JavaScript y Bootstrap 5.

## Estructura

- `index.html`: página principal con navbar, hero, Sobre nosotros, Servicios, Soluciones y Contacto.
- `servicio.html`: página dinámica para consultar el detalle completo de cada servicio mediante `?id=`.
- `css/styles.css`: identidad visual, responsive, Flexbox/Grid y animaciones.
- `js/script.js`: navegación, scroll, menú móvil, reveal al hacer scroll, tarjetas de servicios y formulario hacia WhatsApp.
- `js/services.js`: catálogo y contenido detallado de servicios.
- `img/logo-csi.png`: logotipo de CSI con fondo transparente.
- `img/logo-csi-navbar.png`: versión anterior optimizada para navegación.
- `img/logo-csi-generated-navbar.png`: versión del logotipo tecnológico generado para la navegación.
- `img/logo-csi-original.png`: archivo original suministrado para la identidad visual.

## Tecnologías

- HTML5 semántico
- CSS3
- JavaScript ES6+
- Bootstrap 5.3.3
- Bootstrap Icons
- Flexbox y CSS Grid
- IntersectionObserver para animaciones al entrar al viewport

## Cómo ejecutar

No requiere servidor para la demostración básica. Abre `index.html` en un navegador moderno. Para una experiencia más cercana a producción, puedes usar Live Server en VS Code.
